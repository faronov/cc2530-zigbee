# Security policy

This project is pre-networking research software, not production firmware.
No working Zigbee security or interoperability implementation is claimed.
Do not deploy future experimental builds on a production network merely
because they compile or complete a single join.

For sensitive reports, use
[GitHub's private vulnerability reporting](https://github.com/faronov/cc2530-zigbee/security/advisories/new),
which is enabled for this repository. If it is unavailable, open an issue
requesting a private contact without disclosing exploit details, credentials
or captures.

Never attach real network keys, install codes, OEM dumps, factory identities
or unredacted personal packet captures to a public issue or pull request.
Describe the affected revision, expected/observed behavior and a synthetic
reproducer instead.

There is no promised response SLA or supported production release yet.
